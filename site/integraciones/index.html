Preguntas frecuentes

¿Qué pasa si mi ERP no es Manager? expand_more

Trabajamos con Manager Time ERP, Manager+ y Manager Cloud con conectores ya construidos, y hemos integrado Softland, KAME, DeFontana, Bsale, SAP, Microsoft Dynamics y Salesforce en proyectos a medida. Si el ERP expone una API, una base de datos o archivos de intercambio, se puede integrar.

¿La venta llega al ERP en el momento o cada cierto tiempo? expand_more

Las dos cosas. El método síncrono recibe cada venta en tiempo real; el asíncrono revisa periódicamente y carga lo que no se sincronizó (por ejemplo, si el ERP estuvo fuera de línea). Recomendamos contratar ambos cuando el volumen lo justifica.

¿Qué significa "reglas especiales"? expand_more

Lógica propia de su negocio que el conector debe respetar: una bodega distinta por canal, una lista de precios por marketplace, productos que no se publican, redondeos, márgenes mínimos o cómo tratar los packs. Se definen en el levantamiento y quedan documentadas.

¿Cómo se integra un WMS o un CRM? expand_more

Con un middleware a medida. El levantamiento produce una matriz de documentos (qué entra, qué sale, qué mueve stock) que es el alcance del proyecto; después se desarrollan las APIs, se prueba con datos reales y se pone en marcha con una plataforma de registro de transacciones.

¿Cuánto demora una integración? expand_more

Una integración estándar Manager–marketplace opera en dos a cuatro semanas desde la entrega de accesos. Una integración con WMS o CRM toma de cuatro a ocho semanas incluidas las pruebas. Los proyectos con reglas especiales o varios canales se planifican por etapas.

¿Qué pasa cuando algo deja de sincronizar? expand_more

El costo mensual incluye monitoreo. Cuando una sincronización falla, lo vemos en el panel y lo corregimos; si requiere acción del cliente (por ejemplo, un token vencido del marketplace), avisamos por correo. Las transacciones fallidas se reprocesan desde la plataforma de registro.

¿Qué sistema le gustaría dejar de alimentar a mano?

Descríbalo en dos líneas. Le respondemos si se resuelve con un conector listo o con un middleware a medida, y cuánto toma.
