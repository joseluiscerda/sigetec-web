El piso sobre el que se sostiene todo lo demás.

Una integración que nadie vigila deja de funcionar en silencio. Alojamos, administramos y mantenemos lo que construimos (y lo que usted ya tiene) con un servicio mensual fijo en UF.

Conocer el servicio mensual Ver niveles de soporte
cloud

Microsoft Azure

Azure SQL Database, Azure Web App y App Service para aplicaciones .NET; migración desde servidores virtuales con actualizaciones automáticas de seguridad, respaldos y conexiones cifradas de extremo a extremo.

cloud

Amazon Web Services

Alojamiento de tiendas, middleware y plataformas web; S3 para archivos e imágenes; infraestructura para soluciones completas de comercio electrónico integradas al ERP.

dns

Servidores del cliente

Cuando el ERP vive en su red, instalamos ahí: Windows Server, IIS y SQL Server, con los respaldos y accesos que exige cada integración.

Qué cubre el servicio mensual

  • checkAlojamiento de las integraciones, APIs y plataformas de registro
  • checkMonitoreo: si algo deja de sincronizar, lo vemos antes que usted
  • checkCorrección de errores y pequeñas mejoras dentro de las horas incluidas
  • checkAjustes cuando el ERP, el marketplace, el WMS o la tienda de aplicaciones cambian de versión
  • checkUsuarios o dispositivos incluidos según el producto; adicionales con valor conocido
  • checkEnvío de correos y mensajería (Brevo, WhatsApp) hasta el volumen contratado

Cómo se cobra

Un valor fijo mensual en UF, facturado por adelantado desde el inicio de la marcha blanca, en pesos al valor de la UF del día y con factura electrónica. Las horas fuera de alcance tienen tarifa conocida de antemano. Es opcional, pero es lo que eligen casi todos nuestros clientes: una docena de empresas lo mantienen desde hace años.

Un ejemplo

Un proveedor de la acuicultura tenía un servidor virtual en Azure con su aplicación web y SQL Server en la misma máquina. Lo migramos a Azure SQL Database y Azure Web App en dos semanas: más seguridad, respaldos automáticos, 3 TB de almacenamiento y un costo mensual 10 % menor. Ver el caso.

¿Quién vigila hoy sus integraciones?

Cuéntenos qué sistemas tiene en la nube o en sus servidores. Le proponemos un servicio mensual con lo que incluye y lo que no.
